Quickstart: run kwant locally

Download the app, add an AI account you already have and ask your first question. There's nothing to build. You can also build kwant from source.

What you need

  • A Mac (Apple silicon or Intel) or a Linux x86_64 desktop for the app. On other machines, or on a server, build from source or use Docker (see Install & run).
  • At least one AI account for your bots. Any one of these is enough:
    • a Claude, ChatGPT or Grok account. You don't need to install or sign in to anything first: the Get started card installs the AI when it's missing, and you sign in from the app;
    • an Anthropic, OpenAI or xAI API key, which you add in the card or under Settings → This space → Accounts.
  • Optional: Docker for VM mode and the bots' shared browser, and uv or python3 for the Laya router.

1. Download the app

  • Mac: download the Mac app (a universal .dmg for Apple silicon and Intel), open it and drag kwant to Applications.
  • Ubuntu 22.04 or newer, Debian 12 or newer: download the .deb, then install it with sudo apt install ./kwant_amd64.deb.
  • Other Linux distributions: download the AppImage, then chmod +x kwant_x86_64.AppImage and run it. It needs a normal GTK desktop and FUSE.

Open kwant. The app runs kwant on your computer and keeps an icon in the menu bar (Mac) or the tray (Linux). For a new person, #general opens with the Get started card.

The Mac app is signed ad hoc, not notarized by Apple, so macOS stops it the first time. Click Done, open System Settings › Privacy & Security, scroll down and click Open Anyway next to kwant. On macOS 14 or earlier, right-click the app and choose Open instead.

The first start takes a few minutes. kwant installs its Laya router and downloads its model (about 420 MB) in the background. Bots answer in the meantime, picked by keyword.

Or build from a fresh clone

You need Rust (stable), installed with rustup, and Node.js 20 or newer with npm, to build the web app. The finished binary doesn't need Node.

git clone https://github.com/alexsergivan/kwant.git
cd kwant
make run   # builds the web app, then runs `cargo run -- serve`

Open http://127.0.0.1:8799. On your own computer there's nothing to sign in to. To skip the Laya router, run cargo run -- serve --no-laya.

cargo run -- serve on its own works only once frontend/dist exists, because the binary embeds the web app. After the first make run (or make frontend) you can use either.

2. Get started: choose your AI, sign in, pick a team

New in 0.7.6. A new person's #general starts with one Get started card, in three steps. It replaces the old welcome.

  1. Choose your AI: Claude, ChatGPT, Grok or an API key. When the AI isn't on this computer yet, kwant installs it by itself, with no Terminal and no password for this computer.
  2. Sign in:
    • ChatGPT or Grok: kwant shows a link and a short code. Open the link, enter the code and approve. The card notices by itself when you're done.
    • Claude: press Open claude.ai, allow kwant bots, then paste the code claude.ai shows you.
    • API key: paste an Anthropic, OpenAI or xAI key. Keys are write-only: the app never shows them again.
  3. Pick a team: each ready-made team has a lead, helpers and skills for one job. Or choose Keep the starter bots: Architect, TechLead and DevOps, in #general. Or choose Bring your bots (new in 0.7.7): it opens the importer, so you can bring bots from Grok Bot, ChatGPT, Claude or a file and check a preview first. A finished import completes this step. You can add more teams later.

The importer's Upload a file takes several files in one pick or drop, for example every Grok Bot export you have. kwant packs them into one zip in your browser and shows one preview with every bot, plus the names of any files it couldn't read. A pick is limited to 500 files and 20 MB in all, and a zip can only be imported on its own.

The short-code sign-in for ChatGPT and Grok is in the Get started card. Settings → This space → Accounts still asks you to sign the codex or grok CLI in on this machine (codex login, grok login), and that's also where you add API keys. You can add several accounts per engine, such as a work and a personal one. See Accounts & profiles.

3. Ask your first question

A fresh install's Default space starts with three bots in #general, on the @core-engineering team:

BotTitleGood at
ArchitectSystems ArchitectArchitecture, software design, multi-file engineering
TechLeadStaff Engineer & PrototyperFast reasoning, prototyping, clear explanations
DevOpsSystems & Security EngineerShell, servers, containers, security

Type a question in #general. kwant picks the bot that fits best and shows why. Mention a bot by name (@Architect) to ask it directly, or ask in the team's chat (@core-engineering): when a question needs several views, the lead runs a short discussion and posts one summary.

Running the tests

cargo test               # Rust tests (run `make frontend` first: they need frontend/dist)
cd frontend && npm test  # web app tests
