Alternatives · Hermes Agent

A Hermes Agent alternative that checks the work

kwant is an open-source, self-hosted team of AI bots in one app. A task counts as Verified only when kwant runs the check itself, and a bot that can't go on tells you why. It can bring in your Hermes home and profiles.

Install kwant View on GitHub

Hermes Agent is Nous Research's open-source, self-improving AI agent. According to its README, it creates skills from experience, improves them as it uses them, and talks to you from Telegram, Discord, Slack, WhatsApp, Signal or the terminal through one gateway. kwant is built around something else: a team of bots on hardware you control, where the work is checked before it counts as done.

If you want to try kwant without starting over, it can read your Hermes home and each profile and recreate them as bots. See what the import brings across.

What kwant does differently

  • Verified means kwant checked it. Work shows up as cards on a Mission board. A card turns Verified only when its checks pass: a command such as the tests, a web address that has to answer, a file that has to exist, a review by a teammate who isn't the task's owner, or you pressing Verify. A bot can't verify its own work, and a check a bot adds to its own task waits for your OK. See what "Verified" means.
  • A bot that stops says so, and why. When a step fails or is refused, a bot tries it again, then tries another way. If nothing works, its last line starts with Blocked: and says what would unblock it, and from a team's lead that comes to you as a question card. A lead that stops without handing on, asking you or writing Done: gets up to 2 more turns, then you get one Keep going? card. See handoffs.
  • Nothing extra to install. kwant is one app for Mac or Linux (and a Windows beta), or one program, kwnt, with the web app built in. You don't install Node.js or Python yourself: the apps set up kwant's Laya router on first start, with their own uv when there's no Python, and since 0.7.6 kwant installs Codex without Node. Docker is optional, only for VM mode and the bots' shared browser. Building kwant from source needs Rust and Node.js; the downloads don't. See Install & run.

Hermes works on the same problem in its own way. Its Kanban board, added in v0.13.0, blocks a task when an agent exits before it's complete, and since v0.22.0 interrupted turns aren't reported as done. None of this makes Hermes Agent a bad product. These are the cases where kwant fits better.

Bring your Hermes Agent into kwant

Open Settings › Import. Since 0.8.0 it reads Hermes Agent homes and profiles. In the Mac, Linux and Windows apps, Found on this computer lists ~/.hermes by name and count only. It reads nothing until you pick it, and it never follows a link out of the folder. On a server, pick the folder or a GitHub link instead. Every import shows a preview first, and nothing is created until you press Import.

Your Hermes home, ~/.hermes, becomes one bot, and so does each profile in ~/.hermes/profiles/<name>. kwant brings across:

  • SOUL.md as the bot's soul
  • memories/MEMORY.md as its memories, one per § entry
  • memories/USER.md as what it knows about you
  • the skills you or your agent made, from skills/

Skills that Hermes installs itself (listed in skills/.bundled_manifest) are left out, and the preview names them under Not brought over. kwant never reads .env, auth.json, config.yaml or your past sessions, so no keys or sign-ins come across: you add your logins in kwant. Cron jobs aren't part of the import, so set them up again as routines. One Undo removes the whole import. See Import bots.

What you get in kwant after you move

  • Teams and handoffs. Group bots into teams with a lead and let them pass work with @mentions. Each hand-off gets a card, and the bot that handed it out reviews the result. See teams and handoffs.
  • A mission board. Every check and its evidence on the task's receipt, and checkpoints that let you undo a task's file changes. See the mission board.
  • Routines. Schedule bot work with routines, cron rules and follow-ups. See routines.
  • Approvals. Three approval modes per space or bot, and Flight School tiers (Observe, Sandbox, Act) that set how much freedom each bot has earned.
  • Your models, your accounts. Add multiple Claude, Codex and Grok accounts or API keys with failover. See models and routing.
  • Tools through MCP. Connect Model Context Protocol servers with per-bot access and approval before risky calls. See MCP tools.
  • Spaces. Keep work and home apart, each with its own bots, routines and approval rules. See spaces.

When Hermes Agent is still the better fit

If you want one agent that learns from its own work and writes its own skills, that is what Hermes is built around. It also reaches you in more chat apps than kwant, and it can run on serverless backends such as Modal and Daytona that cost little while idle. And kwant runs on a machine you look after: if your bots live on a laptop that is switched off, routines wait until it is back on. A small VPS with the systemd setup in Install & run avoids that.

FAQ

What is a good open-source alternative to Hermes Agent?

It depends on what you need. kwant is an open-source (AGPL-3.0), self-hosted option built around a team of AI bots that hand work to each other with @mentions, where a task counts as Verified only when kwant runs the check itself. It runs on your laptop, a VPS or Docker.

Can I import my Hermes Agent into kwant?

Yes. Since 0.8.0, Settings › Import reads Hermes homes and profiles, and the desktop apps list ~/.hermes under Found on this computer. Your home and each profile become a bot with its soul, memories, what it knows about you, and the skills you made. Skills Hermes installed itself are left out and listed in the preview, and keys, settings and sessions are never read.

What does "Verified" mean in kwant?

A task on the Mission board turns Verified only when its checks pass: a command such as the tests, a web address, a file, a review by a teammate who isn't the task's owner, or you pressing Verify. The bot that did the work can't verify it, and a check it adds to its own task waits for your OK.

Do I need Python to run kwant?

No. The Mac, Linux and Windows apps and the one-line Linux install use a prebuilt program with the web app built in. kwant's Laya router brings its own uv when the computer has no Python. Only building kwant from source needs Rust and Node.js.

Is kwant free?

The software is free under the AGPL-3.0, and commercial licenses are available. You pay for whatever model accounts or API keys you connect. kwant sends no telemetry to its developers.

What is kwnt?

It is the program you install and run for kwant. Start it with kwnt serve.
