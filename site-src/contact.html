Email

Write to {{CONTACT_EMAIL}} for:

  • Questions about kwant or this website.
  • A commercial license, to use kwant without the conditions of the AGPL-3.0.
  • Privacy and data requests under the GDPR. The privacy policy says what we hold.
  • Press, partnerships and anything else.

Bugs and ideas

Report bugs and suggest features in GitHub issues, where others with the same problem can find them too. For questions and setups to share, use GitHub Discussions.

Security problems

Please don't post a security problem in a public issue or discussion. Report it privately on GitHub instead: open the repository's Security tab and choose Report a vulnerability. The security policy lists what counts and when to expect a reply.
