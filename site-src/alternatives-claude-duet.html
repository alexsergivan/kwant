A Claude Duet alternative you run yourself

kwant is an open-source, self-hosted team of AI bots in one binary. It runs on your laptop, a VPS or Docker, with routines, @mention handoffs and a fail-closed approval broker.

Install kwant View on GitHub

Claude Duet is Anthropic's proactive agent product. According to Anthropic's product page, it can monitor connected apps, send morning briefs, complete tasks in the cloud, and ask for approval before consequential actions. Availability and plan details are on that page and in Anthropic's help centre; we will not restate them here. kwant works the other way round: your bots run on a machine you control, with the logins you already have, and the source code is public.

Why people look for a Claude Duet alternative

The reasons are usually practical:

  • Where the agent runs. Some people want their bots on hardware they control, not on a cloud computer someone else operates.
  • Source you can read. kwant is AGPL-3.0, and the code is public on GitHub.
  • More than one model. kwant bots can run on Claude, Codex or Grok CLI logins, API keys, local Ollama or any OpenAI-compatible server, so you are not tied to one provider. A Claude login is one option among several.
  • Control over what bots do. kwant asks before bots run commands or edit files outside their folder. Payments, locks, doors and alarms always ask, in every approval mode.

None of this makes Claude Duet a bad product. These are the cases where a self-hosted setup fits better.

kwant in one paragraph

kwant is a self-hosted AI agent team: bots share chats and hand work to each other with @mentions. Bots can work on a schedule or while you are away, using routines and cron rules that run on your own machine. You add the logins you already have, several per engine if you like, with failover when one runs out of usage. The program you install is called kwnt (start it with kwnt serve). kwant sends no telemetry to its developers. See all features.

What you get in kwant

  • Teams and handoffs. Group bots into teams with a lead and let them pass work with @mentions. See teams and handoffs.
  • Routines. Schedule bot work with routines, cron rules and follow-ups. See routines.
  • Approvals. Three approval modes per space or bot, and Flight School tiers (Observe, Sandbox, Act) that set how much freedom each bot has earned. Payments always ask.
  • Spaces. Keep work and home apart, each with its own bots, routines and approval rules. See spaces.
  • Your models, your accounts. Add multiple Claude, Codex and Grok accounts or API keys with failover. See models and routing.
  • Tools through MCP. Connect Model Context Protocol servers with per-bot access and approval before risky calls, including a two-field Home Assistant connect. See MCP tools.

When Claude Duet is still the better fit

kwant runs on a machine you look after. If you would rather not run any server or computer yourself, a hosted product is simpler. And if your bots live only on a laptop that is switched off, scheduled routines wait until it is back on. A small VPS with the systemd setup in Install & run avoids that. If you specifically want Anthropic's hosted product and its integrations, start at claude.com/product/claude-duet.

FAQ

What is the best open-source alternative to Claude Duet?

It depends on what you need, but kwant is an open-source (AGPL-3.0), self-hosted option: a team of AI bots in one binary that runs on your laptop, a VPS or Docker, with bots that hand work to each other with @mentions.

Can I self-host Claude Duet?

Check Anthropic's site for what Claude Duet offers. If you want your bots on your own machine, kwant runs on a laptop, a VPS or Docker.

Do I need a Claude account to use kwant?

No. kwant bots can run on a Claude, Codex or Grok CLI login, an API key, local Ollama or any OpenAI-compatible server. A Claude login is one option among several.

Is kwant free?

The software is free under the AGPL-3.0, and commercial licenses are available. You pay for whatever model accounts or API keys you connect. kwant sends no telemetry to its developers.

What is kwnt?

It is the program you install and run for kwant. Start it with kwnt serve.
