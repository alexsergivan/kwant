# Coding

Plans, builds and tests changes in your repo. You merge.

Builds changes in one repo: the lead plans and splits the work, engineers build it on a branch, QA tests it, and the person reviews and merges.

## The team

- **TechLead** (Tech Lead, lead): Turns a request into a small plan and splits the work.
- **Frontend** (Frontend Engineer): Builds the screens: components, styles and the browser side.
- **Backend** (Backend Engineer): Builds APIs and data, and checks what breaks at scale.
- **QA** (QA & Test Engineer): Tests every change and finds the riskiest cases first.

## Starts with

- Pick a repo: Turns on Dev mode for this team and watches one repo.

## Never does

- Merges, pushes to main or tags a release. You merge.
- Changes CI, deploy settings or secrets.
- Puts tokens or keys in code, commits or chat.
