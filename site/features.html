Check in from your phone

kwant has a phone app, with no app store. Read the team's summary, answer questions and approve actions away from your desk, and get a notification when a bot needs you.

  1. Scan the QR code in Settings → All spaces → Signed-in devices → Add a phone or browser, or open your kwant server's https address on the phone.
  2. iPhone: Safari → Share → Add to Home Screen. Android: Chrome → ⋮ → Add to Home screen.
  3. Open it from the Home Screen and turn on Notify me on this device.

Usage

For API-key and custom-API bots, a Usage tab breaks tokens down by purpose, cache and call.

  • One binary

    kwnt has the web app and an SQLite database built in. No Node.js at runtime.

  • Laptop or VPS

    Nothing to sign in to locally. On a server, open the link it prints once. Docker Compose and a systemd unit are included.

  • Any CLI or API

    The claude, codex or grok CLI, or Anthropic, OpenAI or xAI keys.

  • MCP tools

    Add any MCP server and pick which bots can use it. OAuth for servers that need a sign-in.

  • Composio, optional

    Under Settings → This space → Apps & accounts, connect Gmail, Slack, Notion, Linear and more through Composio. Only the bots you pick can use it, and those sign-ins live on Composio's servers, not in kwant's vault.

  • A shared browser

    Bots browse in kwant's own browser profile, or in a container in VM mode.

  • Your data, one folder

    Chats, bots and settings live in ~/.kwnt by default.
