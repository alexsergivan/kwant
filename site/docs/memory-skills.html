AI agent memory, skills and chat search

Bots remember what matters and learn how you like things done. You can read and change all of it, and a skill a bot proposes is only used once you approve it.

Memory

Each bot has a Memory tab. You can add memories there, and the bot can add, update and remove its own. Each one is marked You or Bot, and you can edit or delete any of them.

When you correct how a bot did something in a way that would apply again ("use a table", "always cc Sam"), it saves that as a memory without asking. Below its memories, Lessons from earlier work lists what went wrong on its recent tasks; see Lessons.

  • Up to 100 memories per bot, each up to 500 characters.
  • They go into every turn under What you remember, up to 6 KB.

With the Truth Ledger on (new in 0.6, on from 0.6.5), bots also read the facts you've accepted for their team and space, notes from outside text are labelled Unconfirmed until you confirm them, and notes that conflict are flagged for you to settle.

Skills

A skill is a written procedure, like "how we write a release checklist". It's plain text: a skill never gives a bot new tools.

  • A bot can propose a skill, or a change to one. You Approve, Edit, then approve, or Reject it, and can undo that. A proposed change shows what's different.
  • Approved skills have an on/off switch. Only skills that are on go into the bot's prompt.
  • Use Write a skill in a bot's Skills tab to add one yourself.
  • Skills for a whole space come from an import.
  • When Dev mode finds web code in a team's folder, kwant offers its built-in modern-web skill once, for every bot in the space. It looks up Google Chrome's Modern Web Guidance before a bot writes browser code, and needs Node and the network the first time. Reject or delete it and it isn't offered again. See Dev mode.
  • A skill can be up to 8,000 characters, and a bot can have up to 20 waiting for review.

Skill Foundry

The Skill Foundry turns work a bot has done well into a skill draft for you to review. It's on from 0.6.5, and it needs the Mission board, because it learns from verified tasks.

  • When it drafts: a bot with 3 or more verified tasks of one kind of work in the last 60 days, 70% of them verified, writes down the steps, the inputs, checks that judge the result, the example tasks and the tools it used. At most 2 drafts a day by default.
  • Dry-run replays: each draft is tried on up to 3 of its example tasks, in a scratch copy of their folder. File changes inside that copy run; anything else, like commands, other folders or the browser, is refused and listed as what the bot would have done. Replays run on Claude bots only.
  • You decide: the draft waits in the bot's Skills tab like any proposed skill: Approve, Edit then approve, or Reject. The tools it lists are shown, never granted. The replay report is in the API for now (GET /api/skills/<id>/foundry), not yet on screen.
  • Versions: a new draft for the same kind of work becomes the skill's next version, and an older version can be rolled back.

There's no switch for it in the app yet. To turn it off, use kwant's API with the skill_foundry setting (POST /api/settings with {"skill_foundry": "off"}). A choice you saved before 0.6.5 is kept.

Search

Press Ctrl K (⌘K on a Mac) to search every channel and direct chat in the space you have open. Use the arrow keys and Enter to jump to a result.

Search covers one space at a time. Switch spaces to search another.
