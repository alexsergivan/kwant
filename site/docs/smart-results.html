Smart Results: replies you can sort, chart and copy

When a bot's reply has a table or a list, kwant draws it as a card: a comparison you can sort, a chart, key numbers, findings or a checklist. Every value comes from the reply as written. The reply's text never changes, and anything kwant can't draw stays as text.

What gets a card

Smart Results is new in 0.6.5 and always on. Each reply gets at most one card, worked out once when the reply is saved, without a model call. A reply over 128 KB stays text.

CardMade from
ComparisonA table of options, with columns you can sort
ChartA table of numbers, as a line or bar chart
Key numbersA short set of figures, shown as tiles
FactsLines like Owner: Sam
LinksA list of links or titled items, shown as cards
FindingsA list where each item starts with a severity, such as a review's results
Steps, checklist, timelineNumbered steps, a list with ticks, or dated events
ChecksA task's checks, on its report card
FilesA preview of files a bot shared

Bots are asked to write tables, numbered steps and Label: value lines, so most replies need nothing extra: comparing even two options gets a table, a column each and a row per point. A link in a table counts as its text, so a table with long source links still gets a card. A bot can also point at the table or list it wants drawn, and kwant holds it to the reply: every row must match the reply's table, cell by cell, with the same numbers. Checks and Files cards come from kwant's own records, never from a bot.

Copied, never worked out

  • Word for word. Every value is copied from the reply. Nothing is added up, averaged or rounded, and a chart never puts different units on one axis.
  • Where it came from. Under each card a line says From this reply, From task checks or which attachment it came from.
  • The text is still there. Show as text swaps the card for the reply's own words, and Copy markdown copies the reply as it was written.
  • When in doubt, text. A card that fails a check, or can't be drawn, shows the reply's text instead. Editing a reply removes its card, since the card was copied from the old text.

Copy data and Ask about this

Copy data copies a card's values as Markdown, CSV or JSON, ready for a sheet or another tool.

On a comparison row, Ask about this puts a line such as "About Northdeck in your Host table:" into your message box, so you can ask a follow-up about that row. Nothing is sent until you send it.

Where cards show

Cards show on bot replies in channels and direct chats, on hand-off results from a teammate, on a task's report card and on shared files. Replies from before 0.6.5 stay as they were.
